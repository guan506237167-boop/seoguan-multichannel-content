# 关山阅GEO一稿多平台改写

**第一次使用：先看[详细操作教程](USAGE.md)**（材料模板、可复制指令、样例和结果检查）。

## 输入与输出

输入：原稿/事实资料；明确目标平台、账号身份、读者和目的；字数或口吻偏好。

输出：每平台一份完整Markdown稿件及改写说明；草稿/用户已发/公开核验状态分别记录。

## 工作步骤

1. 提取不可改变的事实、数据、人物归属、来源与禁止公开内容。
2. 按平台任务确定写法：公众号展开事件和方法；知乎先答问题再论证；小红书做可读步骤与场景；LinkedIn面向专业经验。用户偏好优先。
3. 每个平台独立组织标题、开头、正文和结尾，保留必要限定与出处；不是只换标题。
4. 检查个人号和企业号身份；不得把客户案例写成工具作者亲历。
5. 交付可复制全文，另附事实对应表和待补图片说明。若要声称符合平台当前硬性限制，先核对官方规则。

## 使用方法

这是供支持 SKILL.md 的 AI 工具读取的工作流技能，不是独立网站或浏览器插件。

1. 从仓库 **Code → Download ZIP** 下载并解压，保留全部文件及目录结构。
2. 按所用 AI 工具的安装方式导入该目录；是否兼容以实际导入和运行结果为准。
3. 提供所需材料并明确调用 `seoguan-multichannel-content`。支持 `$技能名` 的宿主可使用下方示例。

依赖：不要求 Python、GEO 后台账号或付费 API。需要宿主具备读取所提供材料的能力；宿主模型服务可能有费用。
